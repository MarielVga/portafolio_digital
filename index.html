Proyectos Destacados

💼 Alke Wallet (Caso de Estudio)

Proyecto Principal

Aplicación de billetera digital para gestionar activos financieros de manera 100% digital. Permite a los usuarios tener un control de saldos e ingresos, realizar transferencias rápidas a su agenda y visualizar un historial detallado de movimientos.

El Desafío

  • Diseñar una interfaz Mobile-First utilizando componentes de Bootstrap.
  • Manejar sesiones de usuario, balances y transferencias simulando una base de datos segura.
  • Implementar manejo de errores (rollback) en transacciones fallidas.

La Solución

  • Uso de etiquetas HTML semánticas y el sistema de grillas de Bootstrap para UI/UX.
  • Lógica en jQuery y JS Vanilla para persistencia con localStorage (guardando transacciones y saldos).
  • Alertas interactivas dinámicas para la validación de credenciales en el login.
